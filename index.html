📚 实验指导

实验目的：理解物联网智能安防系统的完整架构，掌握 ZigBee、WiFi、MQTT、Web 可视化等技术。

系统组成： CC2530 ZigBee 温湿度节点 + 协调器 + ESP8266 网关 + 指纹模块 + 云端 MQTT + 前端大屏。

🔧 实验步骤

  1. 检查硬件接线（查看引脚定义表）；
  2. 烧录 ESP8266 固件（需要修改 WiFi 和 MQTT 地址）；
  3. 烧录 CC2530 终端与协调器程序；
  4. 上电后，确认网页显示“已连接到云服务器”；
  5. 按压指纹，观察页面指纹状态更新；
  6. 用吹风机加热 DHT11，观察温度曲线变化；
  7. 修改湿度阈值，触发蜂鸣器报警。

💡 思考题

  • 如何修改代码增加烟雾传感器？
  • MQTT QoS 0 和 QoS 1 的区别是什么？
  • 为什么需要 ZigBee 协调器？能否直接用 WiFi 传输传感器数据？
