📡 实验1.1：CC2530终端与协调器的无线传输

本实验实现CC2530终端节点采集DHT11温湿度数据，并通过ZigBee网络发送到协调器。协调器通过串口将数据转发给上位机。

🎯 实验目的

理解ZigBee协议栈的基本通信原理，掌握CC2530的无线数据收发流程。

🔧 硬件接线

终端：DHT11数据脚接P0_7，VCC→3.3V，GND→GND。
协调器：P0_2(RX)/P0_3(TX)接USB转串口模块（或ESP8266）。

📄 关键代码（终端节点 - 发送部分）

// 基于 Z-Stack 的发送函数示例
void sendTempHumi(uint16 temp, uint16 humi) {
    uint8 data[4];
    data[0] = temp >> 8;
    data[1] = temp & 0xFF;
    data[2] = humi >> 8;
    data[3] = humi & 0xFF;
    
    AF_DataRequest(&dstAddr, &epDesc, SAMPLEAPP_CLUSTERID,
                   4, data, &transID, AF_DISCV_ROUTE, AF_DEFAULT_RADIUS);
}

📥 协调器接收部分

// 在回调函数中接收数据
void SampleApp_MessageMSGCB(afIncomingMSGPacket_t *pkt) {
    switch(pkt->clusterId) {
        case SAMPLEAPP_CLUSTERID:
            uint16 temp = (pkt->cmd.Data[0] << 8) | pkt->cmd.Data[1];
            uint16 humi = (pkt->cmd.Data[2] << 8) | pkt->cmd.Data[3];
            // 通过串口输出
            printf("Temp=%d, Humi=%d\r\n", temp, humi);
            break;
    }
}
