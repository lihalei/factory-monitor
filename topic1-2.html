🔗 实验1.2：ESP8266与协调器间的数据传输

ESP8266通过软串口与CC2530协调器通信，定时发送查询指令，接收并解析温湿度数据。

🎯 实验目的

掌握ESP8266的SoftwareSerial库使用，理解自定义串口通信协议。

🔌 接线

协调器TX → GPIO4 (D2), 协调器RX → GPIO5 (D1), GND共地。

📄 查询指令与帧解析

// 发送查询命令（十六进制）
uint8_t queryCmd[] = {0x3A, 0x00, 0xFF, 0x01, 0xC4, 0x23};
coorSerial.write(queryCmd, sizeof(queryCmd));

// 接收响应（帧头0x3A，帧尾0x23）
void queryDHT11() {
    while(coorSerial.available()) coorSerial.read();
    coorSerial.write(queryCmd, sizeof(queryCmd));
    // 等待回复...
    // 解析: 温度在buf[16]，湿度在buf[17]
}
