🌐 实验1.4：ESP8266通过TCP协议传给客户端

ESP8266启动本地Web服务器，提供REST API，前端通过HTTP轮询获取实时数据。

🎯 实验目的

理解HTTP协议和Web服务器工作原理，实现局域网内的可视化监控。

📄 关键代码（ESP8266 Web Server）

ESP8266WebServer server(80);
server.on("/data", []() {
    String json = "{\"temp\":" + String(temp) + ",\"humi\":" + String(humi) + "}";
    server.send(200, "application/json", json);
});
server.begin();

🖥️ 前端JavaScript轮询

setInterval(() => {
    fetch('/data')
        .then(res => res.json())
        .then(data => { /* 更新页面 */ });
}, 2000);
