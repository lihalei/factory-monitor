☁️ 实验1.5：局域网映射到公网（MQTT协议）

通过MQTT协议将数据发布到公共Broker，实现任何地点访问。前端使用WebSocket订阅，完成跨网络监控。

🎯 实验目的

掌握MQTT物联网通信协议，理解云边协同工作原理。

📄 ESP8266 MQTT发布代码

PubSubClient mqttClient(espClient);
mqttClient.setServer("broker.emqx.io", 1883);
mqttClient.connect("ESP8266_Gateway");
mqttClient.publish("factory/temphumi", "{\"temp\":25.3,\"humi\":60.2}");

🌍 前端订阅（WebSocket）

const client = mqtt.connect('wss://broker.emqx.io:8084/mqtt');
client.subscribe('factory/#');
client.on('message', (topic, msg) => {
    // 显示数据
});
✅ 提示：将前端代码部署到GitHub Pages后，即可通过公网访问。
